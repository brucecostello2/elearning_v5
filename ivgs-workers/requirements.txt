# --- Image / video analysis (WP-44-QUALITY) ---
# numpy was NEVER declared here, and ImageValidator's blank/solid-colour and
# pixel-variance checks sit behind `import numpy`. In the shipped image that
# import raised ImportError and the old code marked both checks PASSED, which
# is how sixteen deformed images scored 1.0 on the first e2e run (swallow
# register instance 24). Declaring it is half the fix; the other half is that
# the checks now report themselves MISSING rather than passed if it is ever
# absent again.
numpy==2.2.1
